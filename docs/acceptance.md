# 实机验收清单 · 0.2.0

自动化测试与上游兼容报告不能代替实机验收。每轮记录板卡版本、日期、电池、X-E5 精确固件、镜头、驱动模式、蓝牙设置及固件 SHA-256。以下硬件检查均待实际连接设备后执行。

## 圆屏与输入

- 首屏只有一个大快门；无录像／录音入口或录像状态。模型名、状态、快门、提示和设备入口在圆屏安全区，不裁切或缺字。
- 右滑进入设备页，左滑返回；电量与连接信息上下滚动，纵向滚动不误触快门。扫描支持 16 个候选、长名称、空列表、重扫与取消。
- 触摸快门与 BOOT 各 20 次检查本地音效，长按一次声音，同时按下不积压。音效不代表相机已拍摄。仅唤醒的首次触摸、配对确认、设备管理不播放快门声。
- 快门长按时滑动、触摸读取错误、同时 BOOT 与触摸均取消并释放；断线时输入不积压。30 秒调暗、60 秒熄屏，首次触摸只唤醒，BOOT 去抖与 PWR 功能保留。
- 检查电压与万用表偏差，USB／电池／充电状态；连续操作两小时检查重启、堆与栈余量、触摸异常和音频错误。

## 富士连接与安全

- 无记录开机待机；在相机开启蓝牙和配对后扫描、选择。未知签名不出现，禁止自动选择第一台；同名相机可通过身份后缀区别。
- 根据实际广播分别验证 Basic 或 Secure。Secure 首次／重新配对显示数字并等待人工确认；拒绝、确认 API 失败、相机拒绝、30 秒握手超时和 120 秒配对超时均停止且可重试。确认后尚未完成加密和必要握手时不能就绪。
- 首次握手最后中性释放成功，保存成功才进入真实可拍摄状态。缺少必需订阅、快门权限、状态读取失败或存储失败不能显示就绪。
- 只有一台保存记录；重启遥控器自动连接。Secure 更换广播地址后按序列信息找到当前地址；相机重启、超距返回、休眠唤醒均能进入真实可操作状态。
- 验证开发板真实断电重启后复用 LTK 恢复加密并到达 Ready。记录是否命中备用地址类型查询；旧绑定恢复失败须报告原始加密状态，不能自动确认、自动新配对或删除绑定。
- 自动连接／恢复最多两轮后停止；主动断开后不重连，点击连接或重启后恢复。取消连接后迟到的连接回调不可启用快门。
- 显式忘记清理目标 metadata／bond，其他记录保留；不自动擦 NVS。两端配对记录不一致时验证明确失败及人工忘记后恢复。

## 拍照

- 20 次短按，每次仅请求一张，AF-S、AF-C、MF 分别记录结果；等待必须从写入确认计时。
- 相机连拍档位长按，松手停止；对焦／快门两次写入之间取消，不能发送已取消的拍摄参数。
- 按住快门时断线，恢复时中性释放且无残留连拍、补拍或旧操作重放。
- 没有合焦／曝光反馈时仅显示“指令已发送”，不展示虚假计数或成功确认。

## 构建与发布

- 精确 ESP-IDF 5.5.3 编译；主机测试、LVGL 输入回归、中文覆盖与格式检查通过。
- macOS／Windows 11／Linux 安装、构建、打包及实际 USB 刷写分别验收；构建通过不能代表所有平台 USB 已测试。
- 多串口必须显式指定；普通刷写保留 NVS；损坏固件包在调用 esptool 前被校验拦截。
- 清单标记 `upstream-implemented-hardware-unverified`，实机完成之前不得标记兼容性已验证。
