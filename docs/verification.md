此前身份恢复修复保留已有绑定，从本端 bond 恢复实际分发的本机 IRK。一次真实开发板关机开机后，日志记录 3880 ms 完成原绑定加密、12280 ms 完成握手并进入 Ready，没有数字比对、新配对或删除绑定。补充解析条目错误传播后再次刷机，记录 3636 ms 恢复加密、12086 ms Ready。诊断与边界见[重连调查](reconnect-investigation.md)。日志保存在本机忽略的 `build/log/`，不随项目分发。
