# 富士 Basic / Secure 协议

## 来源与验证边界

本项目从手柄外设方案迁移到 furble 使用的富士手机遥控协议：遥控器主动扫描并连接相机，不再广播手柄服务，也不再使用 `00 00 XX` 手柄报文。

协议依据是 [furble 固定提交 0cac22a](https://github.com/gkoh/furble/tree/0cac22aacc3d9ef250be40849118af78a5f39f27/lib/furble) 的 Fujifilm、FujifilmBasic、FujifilmSecure、Device 和 Camera 源码，许可见 `LICENSES/furble-MIT.txt`。生产代码可用的含义是有可追溯协议来源与运行时完整握手；**尚未在本项目的 X-E5 上验收**，不宣称拍摄、对焦或连拍已经实测成功。

## 广播与握手

厂商数据 company ID 为小端 `d8 04`。Basic 必须具有七字节厂商数据、type `02` 和上游 CR/XApp 服务；后四字节是 token。Secure 必须具有八字节厂商数据和上游 Secure 服务，后五字节作为相机序列信息。名字只用于显示，不用于授权或选择协议。未知签名不展示、不尝试连接。

Basic：主动连接首次选择或已保存地址，写入 token、稳定的 `camera-rc-xxxxx` 标识，按上游顺序订阅两个 indication、两个 notification 和第三个 indication，然后解析快门特征。

Secure：首次通过 Secure 广播选择；重连时扫描配对服务广播，匹配已保存的五字节序列信息并使用当前广播地址。建立加密、bond 与认证后读取四字节状态，保留前三字节、将末字节置 `20` 写回；写标识，按上游顺序执行六项必需订阅、五项可选订阅与必需的定位同步间隔订阅，写入十秒间隔，最后解析快门特征。握手所需定位配置会保留，不发送位置或伪造定位数据。

首次或显式重新配对时，安全数字比对在遥控器显示六位数字，用户与相机核对后确认；拒绝、确认失败或超时关闭会话。BLE 回调只投递 Compare 事件，owner 验证活动会话与阶段后处理。过期、取消、断线或队列满关闭后的事件不发送确认。当前 IO 能力是 DisplayYesNo；不能处理的 PIN 输入／显示动作失败关闭，不使用默认 PIN。仍要求协商成功、链路加密和 bond，再进行全部必要 GATT 握手；不额外强制上游未检查的 authenticated 标志，相机无数字比对 IO 时可按协议协商加密的 Just Works。密钥由 NimBLE NVS 保存，不打印 token、序列信息或密钥。

构建另移植上游 `patches/ble_gap.patch`：`ble_gap_security_initiate()` 按当前身份查不到记录时，交换 PUBLIC／RANDOM 类型重查；有 LTK 先恢复加密。补丁仅作用于构建目录的源码副本，不修改共享 IDF；原始匹配位置必须唯一，否则停止构建。蓝牙库编译时关闭 `BLE_RESTART_PAIR`，保留 `PINKEY_MISSING` 的原始加密事件；不自动删除绑定。已保存相机连接时 owner 要求存在 LTK，且任何意外数字比对均以认证错误关闭，不静默重配对。只有显式配对流程可以创建新密钥。

订阅通过动态发现真实 CCCD 句柄完成，不假定 `value_handle + 1`。所有 UUID 和握手条件来自固定上游，句柄从相机发现；缺少必需属性或权限时失败。可选订阅失败允许继续，其余操作失败关闭。

## 拍摄与就绪

控制为快门特征的两次带响应写入：`01 00`，再写参数。对焦 `03 00`，快门 `02 00`，释放 `00 00`。每次写入都等待确认。连接握手最后执行中性释放，两次写入均成功后保存首次配对并发布 Ready。存储失败不进入 Ready。

拍摄请求携带操作 ID，完成事件同时带会话代次。对焦等待和快门脉冲从相应写入确认后计时。取消丢弃未发送的正向参数，释放通过独立通道优先执行；不能撤回已在空中的 ATT 请求，会在它完成后立即释放。写入超时或释放失败断开；重连必须重新中性释放。断线后不重放拍摄请求。

ATT 确认只表示远端收到写入，不证明已曝光或合焦。没有相机反馈时界面显示“指令已发送”。此协议没有已验证的独立录像命令，已移除录像按钮、状态行及事件入口。

## 生命周期与持久化

只保存一台。无记录时开机待机，用户点击扫描、选择相机；扫描结果最多 16 台。保存后开机自动连接，意外断线有限恢复，主动断开后停止直到点击连接或重启。Basic 按上游直接连接已保存地址；Secure 先扫描至多 60 秒，匹配序列信息后连接当前地址。

首次扫描与配对总窗口 120 秒，重扫不延长窗口；建链 10 秒；建链后安全与握手合计 30 秒。保存目标最多尝试两轮，间隔一秒；恢复就绪后重置重试计数。连接中的取消、断线或队列满使旧会话失效。

记录保存到 `camera_rc/fuji_peer_v1`，包括 schema、协议、名称、地址类型、身份地址及 token／序列信息。旧手柄 `peer` 记录不能转换，不自动删除；显式忘记删除相关记录及目标 bond，不清空 NVS，不删除其他设备 bond。普通刷写保留 NVS。

本机 IRK 另存 `camera_rc/local_irk_v1`（16 字节）。owner 在 host 同步后、扫描前读取；首次升级从已保存相机的本端 bond 恢复此前已分发的 IRK，没有任何 bond 时才采用初始化的活动值。保存提交成功后校正活动 IRK，并恢复所有对端的解析条目。失败停止连接，含 iterator 回调错误也须显式保留；不删除旧绑定，不在“忘记相机”时改变本机身份。不打印 IRK、LTK、token、序列信息或摘要。
